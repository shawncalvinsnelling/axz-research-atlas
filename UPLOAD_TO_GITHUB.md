# Upload Instructions

## 1. Create the repository

Create a public GitHub repository named:

```text
axz-research-atlas
```

Owner:

```text
shawncalvinsnelling
```

## 2. Upload this package

Extract the ZIP and push all files:

```bash
git init
git add .
git commit -m "Initial AXZ Research Atlas"
git branch -M main
git remote add origin git@github.com:shawncalvinsnelling/axz-research-atlas.git
git push -u origin main
```

Or upload through GitHub's web UI.

## 3. Enable GitHub Pages

In the repository:

```text
Settings → Pages → Deploy from branch → main → /docs
```

Expected site URL:

```text
https://shawncalvinsnelling.github.io/axz-research-atlas/
```

## 4. Add website to repo About box

On the repository homepage, click the gear icon next to **About** and paste:

```text
https://shawncalvinsnelling.github.io/axz-research-atlas/
```

That gives reviewers a direct clickable website from the repo page.

## 5. Pin the repository

Pin `axz-research-atlas` to your GitHub profile so reviewers see it first.
